# Deney - Personal iOS Application & Security Research Project

kemal88kaya@gmail.com is owner of this repo

**Deney** is a personal iOS application and software development project focused on defensive security testing, static code auditing, and secure coding practices.

## 🎯 Project Scope & Security Objectives
A local sandbox environment and codebase used to evaluate and harden mobile security controls:
- **Static Code Auditing:** Reviewing Swift/iOS architectures for common vulnerabilities.
- **Data Protection:** Testing Keychain storage, local encryption, and credential management.
- **Network Security:** Checking App Transport Security (ATS), TLS configurations, and API integrity.
- **Dependency Auditing:** Monitoring third-party packages for known flaws.

## 🛡️ Responsible Use & Scope Limitation
All security testing and code analysis are strictly limited to this personal codebase and local test devices. No external or third-party systems are targeted.
